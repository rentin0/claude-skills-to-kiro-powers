# データベースクエリヘルパー

このスキルは、様々なデータベースシステムでのクエリ作成と最適化を支援します。

## 対応データベース

- SQL（MySQL、PostgreSQL、SQLite）
- MongoDB
- Redis

## 主な機能

### 1. クエリ生成
ユーザーの要件から最適なクエリを自動生成します。

### 2. パフォーマンス分析
クエリの実行計画を分析し、最適化の提案を行います。

### 3. スキーマ検証
データベーススキーマに対するクエリの妥当性を検証します。

## 使用例

```sql
-- ユーザーテーブルから特定の条件でデータを取得
SELECT * FROM users WHERE created_at > '2024-01-01' ORDER BY created_at DESC;
```

## ベストプラクティス

- インデックスを活用したクエリ設計
- N+1 問題の回避
- トランザクション管理
